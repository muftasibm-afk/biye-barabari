# Biye Bari Crashers
Phaser 3 + Vite + PeerJS. No game server, free to host.

## Run locally
npm install
npm run dev

## Deploy free on Vercel
1. Push this folder's contents to the ROOT of a GitHub repo (package.json must be at the root).
2. Vercel > Add New Project > import the repo. It detects Vite on its own:
   build command `npm run build`, output directory `dist`. Click Deploy.
3. Share the link. One friend creates a room and shares the 4-letter code.
